# Roadmap

Gitfleet 0.2.0 ships the provider-neutral GitHub and GitLab command surface,
user documentation, the marketing homepage, bulk repository cloning, and
declarative label workflows. Candidate 0.3.0 work includes broader multi-profile
workspace execution, declarative fleet policies, and deeper provider-specific
operations.

Roadmap items are proposals rather than compatibility commitments. Confirmed
release work should move into `PLAN.md` before implementation.
